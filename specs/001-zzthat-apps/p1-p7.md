# P-1 to P-7, operator authorized 2026-10-19

The recommended defaults in zzThis `specs/decisions-2026-10-19.md` are implemented in the iOS reader on this branch. They are not a qualification receipt. Android is not changed in this branch: a marker-hit change without the exact-first filter would pair a middle `22`.

P-5 is the scoring wording, not a corpus. N5 is issued codes with the two data words swapped, minimum 300 final items per device-matrix entry. N7 is field codes and handles with markers, including a `22` part, minimum 300. A correct read of an N7 field code or handle is not a negative false-valid. This branch does not bump `ZZ-OCR-QUAL-001`. The schema change stays in the zzThis protocol pull request.

The decoder flag is off. Release does not turn it on. A tolerant pair is Clarify, including when a PASS receipt would otherwise allow Accept. A tolerant write check does not pass.
