# Decisions: zzThat apps

Decided 2026-10-04 from the zzThis pin `0a5c9b93e8f8266ff9d0855f4afe2dafbe1d26d7`, from zzThis issues #57 (Q33) and #58 (Q39) as those issues state their defaults, and from native thin-client practice where zzThis is silent. This repo does not change zzThis.

Create stays gated until the zzThis resolver adds free public codes (zzThis spec 002 FR-016, a v2 item). zzThis spec 005 adopted the DEP proposals on 2026-10-04. The HTTP shapes are the pinned [`contracts/zzthis-v1.openapi.yaml`](../../contracts/zzthis-v1.openapi.yaml), which the zzThis build implements. They are not implemented here.

Corrected the same day, after the first close: ZQ1 and ZQ2 name zzthis as the web client, the central server, and the marketing page the launch link uses. ZQ11 is reversed to server-chosen words. ZQ18 is amended to native provider sign-in plus an ID token with a server nonce.

The app cache follows zzThis spec 005 FR-018 [DANNY 2026-10-04] (Q26) and FR-028: honor `Cache-Control`, which is `public, max-age=60, stale-while-revalidate=300` for an active reusable public unauthenticated resolve, and `no-store` on every other `/v1` response. FR-041 sets the app's 60 seconds online and 360 seconds offline (ZQ26). A photo upload, when `photo_reads` is true, is JPEG only and at most 8 MiB. zzThis Q18 was decided in zzThis on 2026-10-04 ([zzThis #74](https://github.com/Zero-State-LLC/zzthis/issues/74)): no cloud reader in v1. So `GET /v1` reports `photo_reads: false`, the photo read returns `not-ready`, and the apps do not offer the upload. Sign-in follows zzThis spec 005 FR-020 and FR-021 [DANNY 2026-10-04] (Q66): the platform's own Apple or Google sign-in, a server nonce, and the provider ID token.

ZQ22 to ZQ26 were added on 2026-10-04 with the zzThis pin `d6143be99b2946902a84a89b1584c5907e640a2d`, from the one-shot build review (zzThis `specs/analysis-2026-10-04.md`). ZQ27 and ZQ28 were added on 2026-10-04 from the pre-build audit and decided on 2026-10-05 by established practice, as Danny asked on zzThis #75. Danny can reopen either. No issue is filed for them yet.
